# Smart Stock 个人试用版

1. 在 Google Sheet 的测试副本打开「扩展程序 → Apps Script」。
2. 把 [Code.gs](Code.gs) 的内容贴到默认的 Code.gs。点「＋ → HTML」，命名为 Index，再贴入 [Index.html](Index.html)。
3. 保存后，在函数下拉菜单选择 setupTrial，再点「运行」并授权。回到 Sheet，在「试用物品」分页的 A2 开始每行填一个品名。
4. 点击「部署 → 新部署 → 网页应用」。执行身份选「我」，访问权限选「仅限自己」。打开部署给的网址，选择物品和数量后保存。
5. 到 Sheet 的「试用领用记录」分页查看记录。

此版本只登记领用。它使用内置 Apps Script 服务和独立的试用分页，不计算库存余额。项目已有旧脚本时，请用干净的测试项目，避免同名函数冲突。
